---
title: Running your app
description: Start and watch your dev servers from the Run pane.
---

Press ⌥⌘7 to open **Run** in the bottom pane. It lists the repository's run
commands, the same ones you set up in the Mac app, with each one's output.

| Key           | Does                                   |
| ------------- | -------------------------------------- |
| `j` `k`       | Next and previous command              |
| Return        | Start or stop it                       |
| `R`           | Restart it                             |
| `a`           | Add a command                          |
| `d`           | Remove the command                     |
| `A` `X`       | Start all, stop all                    |
| `i`           | Type into its output                   |
| ⌃O            | Stop typing into it                    |

The bottom bar shows how many commands are running.

The terminal app runs its own processes, separate from the Mac app's, and
stops them when you quit.
