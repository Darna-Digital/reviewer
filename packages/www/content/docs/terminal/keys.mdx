## A note on ⌘

The ⌘ shortcuts are the Mac app's. They only reach Reviewer in terminals that
support the kitty keyboard protocol and don't keep ⌘ for themselves, such as
Ghostty, kitty, WezTerm, or iTerm2 with CSI u turned on. Most ⌘ shortcuts
have a ⌃ or plain-key alternative, listed next to them.

## Anywhere

| Mac          | Also         | Does                                   |
| ------------ | ------------ | -------------------------------------- |
| ⌘K           | ⌃K `:`       | Command palette                        |
| ⇧⌘O          |              | Go to file                             |
| ⇧⌘F          |              | Search in files                        |
| ⌥⌘1 ⌥⌘2      |              | Browse, Review                         |
| ⌘G           |              | Switch between Browse and Review       |
| ⇧⌘B          | ⌥⌘4          | Switch branch                          |
| ⌥⌘5 ⌥⌘6 ⌥⌘7  |              | History, Usages, Run                   |
| ⌘B           | ⌃B           | Show or hide the bottom pane           |
| ⌃⌘S          | `\`          | Show or hide the sidebar               |
| ⌘R           | ⌃R `r`       | Refresh                                |
| ⌘,           | ⌃T           | Theme and appearance                   |
| ⌘O           | `O`          | Open a workspace                       |
|              | Tab          | Next pane                              |
|              | `?`          | Keys for where you are                 |
|              | `q`          | Quit                                   |

## Reviewing

| Key            | Does                                         |
| -------------- | -------------------------------------------- |
| `t` `T`        | Compare against…, or switch to uncommitted   |
| `s`            | Split or unified                             |
| `E`            | Changed hunks or full files                  |
| `W`            | Wrap long lines                              |
| `]` `[`        | Next and previous file                       |
| `c`            | Comment on the line                          |
| `n` `N`        | Next and previous comment                    |
| `m`            | Every comment                                |

## Committing

| Key            | Does                                         |
| -------------- | -------------------------------------------- |
| `space`        | Include or leave out the file                |
| `i`            | Write the message                            |
| ⌃G             | Write the message for me                     |
| ⌃S ⌘Return     | Commit                                       |
| ⌥⌘K            | Commit and push                              |
| `F` `L` `P`    | Fetch, pull, push                            |

## Moving around

| Key            | Does                                         |
| -------------- | -------------------------------------------- |
| `j` `k`        | Down and up                                  |
| `g` `G`        | Top and bottom                               |
| ⌃D ⌃U          | Half a page down and up                      |
| ⌃O ⌥←          | Back to where you jumped from                |
| ⌥→             | Forward again                                |

A number before a move repeats it: `10k` moves up ten lines.
