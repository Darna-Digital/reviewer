## Run commands

Most projects need a few things running while you work: a dev server, a
queue worker, a database. Save them once as **run commands**, and start them
all with one click.

<Screenshot name="run-services" width={2456} height={942} alt="The Run surface, with services running and the dev server's output" />

Open **Run** in the bottom pane. To add a command, click **+** in the footer
and enter the command line. Each command shows whether it is running, and the
selected one shows its output with buttons to start, stop and restart it.

**Start all** at the bottom brings the whole project up at once. In a
workspace, Run lists the commands of every repository, so Start all brings up
every repository's commands.

Run commands are saved with the repository, so the terminal app sees the same
ones.

## Terminal

Open **Terminal** in the bottom pane for a shell in the project's folder.
Rename a terminal by clicking its name in the bar above it.

## The Projects widget

Reviewer has a desktop widget that puts your projects one click away.
Add it from the widget gallery: there are two, **Recent projects** and
**Favorite projects**, each in three sizes.

Clicking a project opens it in Reviewer and starts its run commands, so it is
ready to work on. If another project is already open, it opens in a new
window.
