## General

| Shortcut     | Does                                  |
| ------------ | ------------------------------------- |
| ⌘K           | Command palette                       |
| ⇧⌘O, ⇧⇧      | Go to file                            |
| ⇧⌘F          | Search in files                       |
| ⌘O           | Open a repository or workspace        |
| ⌥⌘O          | Add a repository to the workspace     |
| ⌘,           | Settings                              |

## Window

| Shortcut     | Does                                  |
| ------------ | ------------------------------------- |
| ⌃⌘S          | Show or hide the sidebar              |
| ⌘B           | Show or hide the bottom pane          |
| ⌘G           | Switch between Code and Sessions      |
| ⇧⌘] ⇧⌘[      | Next and previous tab                 |
| ⌘W           | Close the tab                         |

## Sessions

| Shortcut     | Does                                  |
| ------------ | ------------------------------------- |
| ⌘T           | New session                           |
| ⌘1 to ⌘9     | Go to a session                       |

## In lists and pickers

| Key          | Does                                  |
| ------------ | ------------------------------------- |
| ↑ ↓          | Move through the rows                 |
| Return       | Pick the selected row                 |
| Escape       | Clear the search, then close          |
| Backspace    | In the palette, with an empty search: go back a level |
