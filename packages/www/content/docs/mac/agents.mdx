You can run Claude Code and Codex inside Reviewer, in **sessions**. A session
is one conversation with an agent, working in the repository you have open.

## Starting a session

Press ⌘T to start a new session. Choose the agent and model, type what you
want, and send it. The session gets a tab of its own in the toolbar.

<Screenshot name="agent-models" width={2492} height={1564} alt="The model picker, with Claude and Codex models side by side" />

Under the prompt are the session's settings:

- **Model**: the agents are listed down the side of the picker. Star the
  models you use most to keep them at the top.
- **Effort**, **mode** and **access**: each agent only shows the options it
  supports.

To give the agent a screenshot, paste it, drop it anywhere on the session, or
click the attach button. Drag the top edge of the prompt box to make it taller.

A new session starts with the settings you used last.

## Following a session

While the agent works, Reviewer shows what it is doing. Each turn's tool calls
are folded into one line. Click it to see every step, and click a step to see
its input and output.

You can stop the agent at any time with the stop button.

## Finding sessions

The **Sessions** tab lists every session, from every project, newest first.
Search it, or filter it by project or by how recent it is. Right-click a
session to open it in its own tab or to delete it.

| Shortcut   | Does                                      |
| ---------- | ----------------------------------------- |
| ⌘T         | New session                               |
| ⌘1 to ⌘9   | Go to a session's tab                     |
| ⌘G         | Switch between Code and Sessions          |
| ⇧⌘] ⇧⌘[    | Next and previous tab                     |
| ⌘W         | Close the tab                             |

You can also drag tabs to reorder them, and middle-click a tab to close it.
