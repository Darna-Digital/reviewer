---
title: Settings
description: Appearance, themes, and the accounts Reviewer uses.
---

Open Settings with ⌘, or from the Reviewer menu.

## Appearance

Choose **System**, **Light** or **Dark**. System follows your Mac as it
changes.

## Theme

Pick one theme for light mode and one for dark. Reviewer's own pair is the
default. Pierre's themes and the Shiki themes are also there, including Tokyo
Night, Catppuccin, Dracula, Nord and Solarized.

The theme colours the whole window, not only the code. The sidebar, panels
and text are all taken from it.

## Git identity

Shows the name and email your commits are made with in this project, and the
command to change them.

## GitHub

Shows which GitHub account Reviewer is signed in as, if any. See
[Pull requests](/docs/mac/pull-requests#connecting-to-github) to connect one.

## Languages

Shows the language servers Reviewer uses, and installs intelephense for PHP
if you don't have a PHP language server.
