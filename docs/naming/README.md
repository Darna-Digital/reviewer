# Naming study: candidates to replace `byconvo`

Brief: a name in the register of Cursor, Warp and Zed — one or two syllables, a real
word, hard edges. 85 candidate words checked across 6 domain patterns (510 domains).

Probed 2026-08-25. **Every bare `.com` in the list is registered**, which is why the
`run—` prefix carries most of the open positions.

## Method, and what `FREE` is worth

`dns-availability-check.py` sends a UDP `NS` query per domain to four public recursors
(Google, Cloudflare, Quad9). Each `NXDOMAIN` is confirmed with a follow-up `SOA` and `A`
query before the name is called free. Validated against known-registered and known-free
control names first.

**`FREE` is a strong signal, not proof.** It means no nameservers exist for the name. A
domain can be registered and left undelegated, or sit in redemption after expiry, and
still answer `NXDOMAIN`. Confirm at a registrar before committing to one.

RDAP — the authoritative registration check — was unavailable: the network egress policy
blocks `rdap.verisign.com` and its mirrors, along with DNS-over-HTTPS and TCP port 53.
UDP DNS was the only channel.

22 names returned `SERVFAIL` from every resolver (serialized, retried, DNSSEC checking
disabled) and are marked `?` rather than guessed at.

Trademark and existing-product collisions are noted on the shortlist but were not searched
exhaustively. Clear the finalist properly before filing.

## Reproducing

```sh
while read w; do
  for p in "$w.com" "run$w.com" "get$w.com" "$w.dev" "$w.app" "$w.sh"; do echo "$p"; done
done < candidate-words.txt | python3 dns-availability-check.py
```
